# My First Project

This is my very first repository, created as part of the **"Vibe Coding"** course to practice fundamental development workflows.

### 1. What it is (Что это)
A basic Python project environment set up to learn Git version control, repository management, and GitHub integration.

### 2. How to run / verify (Как запустить/проверить)
1. Clone this repository or open the project folder.
2. Ensure you have Python installed.
3. Run the main script using the command:
   ```bash
   python main.py
   ```

### 3. What I did (Что я сделал)
* Initialized a local Git repository and connected it to GitHub.
* Created a `.gitignore` file to exclude the heavy `venv/` directory from being tracked.
* Added the core `main.py` file.
* Fixed a filename typo (`readme.nd` to `README.md`) using Git commands and structured the documentation.
* Successfully pushed all milestones to the remote repository.

### 4. What was challenging / What I learned (Что было сложным / Что понял)
* **The challenge:** At first, it was confusing to understand when and how to make commits, and how to fix errors when commands were typed incorrectly (like missing spaces).
* **What I learned:** I now clearly understand that a commit is a snapshot of my progress. I learned how to move files, clean up untracked folders with `.gitignore`, and confidently use basic Git commands (`add`, `commit`, `push`).
